# Image Assets Directory

Drop your project screenshots and banners in this folder with the following filenames to have them display in the main `README.md`:

| Filename | Recommended Dimensions | Description |
|---|---|---|
| `banner.png` | 1280 × 400 px (or 1920 × 600 px) | Main hero banner / cover art for the top of the README |
| `dashboard.png` | 1920 × 1080 px (16:9) | Screenshot of the main dashboard, summary cards & metrics |
| `live-scan.png` | 1920 × 1080 px (16:9) | Screenshot of the live scanning progress, progress bar & terminal logs |
| `attack-surface.png` | 1920 × 1080 px (16:9) | Screenshot of vulnerability findings, attack vectors, or radar charts |
| `executive-report.png`| 1920 × 1080 px | Screenshot or preview of the generated security assessment report |

> **Tip:** PNG or WebP formats are recommended for optimal clarity and crisp typography on GitHub.
